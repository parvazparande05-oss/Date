# ربات دوستیابی تلگرام (نسخه ۲ — با MBTI، پریمیوم و پنل ادمین)

## امکانات کامل
- ثبت‌نام: نام مستعار، سن (۱۸+)، جنسیت، هدف آشنایی، استان/شهر (کل ایران)، بیو، ۶ ویژگی اخلاقی، ۱ تا ۵ عکس، ویس معرفی ۳۰ ثانیه‌ای (اختیاری)
- **آزمون MBTI** ۱۶ سوالی داخل ربات، یا وارد کردن دستی تایپ؛ قابل ویرایش از منو («🧠 ویرایش MBTI»)
- مرور پروفایل با لایک / رد / **سوپرلایک** ⭐️، امکان دیدن عکس‌های بعدی و شنیدن ویس معرفی
- سیستم مچ + **تحلیل سازگاری MBTI** بعد از مچ: درصد سازگاری، نقاط قوت، نقاط ضعف (فقط پریمیوم)، پیشنهاد بهبود رابطه
- چت ناشناس داخل ربات با دکمه پایان چت و بلاک/گزارش
- **مچ طلایی روزانه** خودکار (پوش هر روز ساعت مشخص) + دکمه دستی در منو
- **جدول «ستاره هفته»**: رتبه‌بندی کاربران بر اساس تعداد مچ
- **سیستم دعوت (رفرال)**: هر دعوت = ۵ سکه هدیه
- **تأیید هویت با سلفی**: کاربر سلفی می‌فرسته، ادمین با یک دکمه تأیید/رد می‌کنه و بج ✅ می‌گیره
- **مدل Freemium**: محدودیت روزانه‌ی مرور/سوپرلایک برای رایگان؛ پریمیوم = نامحدود + تحلیل کامل + اولویت
- **تخفیف افتتاحیه**: هر کاربر تازه‌ثبت‌نام‌شده به‌صورت خودکار N روز پریمیوم رایگان می‌گیره (قابل تنظیم/خاموش‌کردن توسط ادمین)
- **پرداخت با Telegram Stars** (ارز داخلی تلگرام) — بدون نیاز به درگاه بانکی یا احراز هویت کسب‌وکار
- **پنل ادمین کامل** با دستورات متنی ساده (بدون نیاز به دانش فنی)

## مرحله ۱: ساخت ربات و گرفتن توکن
۱. به [@BotFather](https://t.me/BotFather) پیام بده، `/newbot` بزن، اسم و یوزرنیم انتخاب کن، توکن رو نگه دار.
۲. آی‌دی عددی خودت (برای پنل ادمین) رو از [@userinfobot](https://t.me/userinfobot) بگیر.
۳. **فعال‌سازی Telegram Stars**: نیازی به کار اضافه نیست؛ همه ربات‌ها به‌صورت پیش‌فرض می‌تونن با Stars پول بگیرن. کاربر داخل تلگرام Stars می‌خره (با کارت یا اپ‌استور/گوگل‌پلی) و مستقیم به ربات پرداخت می‌کنه؛ سهم تلگرام از این پول کم می‌شه و بقیه‌ش قابل انتقال به کیف پول شماست (از تنظیمات ربات در BotFather).

## مرحله ۲: میزبانی رایگان روی Railway
۱. [railway.app](https://railway.app) → ثبت‌نام با گیت‌هاب
۲. یک ریپازیتوری بساز، تمام فایل‌های این پروژه رو آپلود کن
۳. Railway → New Project → Deploy from GitHub repo
۴. متغیرهای محیطی (Variables):
   - `BOT_TOKEN` = توکن از BotFather
   - `ADMIN_IDS` = آی‌دی عددی خودت (اگه چند ادمین داری با کاما جدا کن: `111,222`)
   - (اختیاری) `LAUNCH_DISCOUNT_DAYS` = عدد روزهای تخفیف افتتاحیه (پیش‌فرض ۳۰)
   - (اختیاری) `PREMIUM_PRICE_STARS_MONTH` = قیمت پریمیوم به Stars (پیش‌فرض ۱۵۰)
۵. Start Command: `python main.py`
۶. Deploy کن؛ ربات آنلاین می‌شه.

> نکته: چون از Long Polling استفاده می‌شه، پروسه باید همیشه روشن بمونه. وقتی جدی‌تر شدی، یک VPS ارزون (Hetzner و مشابه، ۳-۵ دلار/ماه) بگیر و همین فایل‌ها رو بدون تغییر روش اجرا کن.

## مرحله ۳: تست محلی (اختیاری)

export BOT_TOKEN="توکن شما"

## پنل ادمین — چطور روزانه ربات رو مدیریت کنم (بدون نیاز به کدنویسی)
همه‌چیز با دستورات ساده در چت خودت با ربات انجام می‌شه:
- `/admin` → آمار کلی (تعداد کاربر، مچ، پریمیوم، گزارش، بن‌شده‌ها)
- `/broadcast` → بعدش متنی که می‌خوای به همه بفرستی رو تایپ کن (پیام همگانی)
- `/ban USER_ID` و `/unban USER_ID` → مسدود/رفع مسدودی یک کاربر
- `/reports` → دیدن آخرین گزارش‌های تخلف
- `/pending` → دیدن سلفی‌های در انتظار تأیید هویت، با دکمه تأیید/رد
- `/discount_on` و `/discount_off` → روشن/خاموش کردن تخفیف افتتاحیه در لحظه

## درباره‌ی زرین‌پال (اختیاری، برای بعداً)
Telegram Stars برای شروع کافی و بدون دردسره چون نیاز به مجوز کسب‌وکار نداره. اگه بعداً خواستی پرداخت ریالی مستقیم (زرین‌پال/آیدی‌پی) اضافه کنی، این کار نیاز به یک وب‌هوک عمومی و merchant ID داره؛ وقتی به اون مرحله رسیدی بگو تا دقیق و تست‌پذیر اضافه‌اش کنم — الان چیز نصفه‌کاره‌ای که ممکنه خراب کار کنه نذاشتم.

## نکات امنیتی و قانونی مهم
- حداقل سن ۱۸ سال به‌صورت سخت‌گیرانه چک می‌شه (`config.py` → `MIN_AGE`).
- گزارش تخلف و بلاک همیشه در دسترس کاربرهاست؛ گزارش‌ها رو با `/reports` مرتب چک کن.
- محتوای عکس/بیو کاربران به‌صورت خودکار فیلتر نمی‌شه؛ تأیید سلفی (`/verify` سمت کاربر، `/pending` سمت تو) کمک می‌کنه اعتماد بالا بره، ولی جایگزین نظارت انسانی نیست.
- قبل از انتشار عمومی، یک متن کوتاه «قوانین استفاده» و «حریم خصوصی» بنویس و لینکش رو در پیام خوش‌آمد بذار.

## ایده‌های رشد و وایرال شدن سریع (خلاصه)
1. **MBTI کمتر توی ربات‌های ایرانی هست** — روی همین در تبلیغاتت تأکید کن.
2. تحلیل نقاط قوت/ضعف بعد از مچ محتوای اسکرین‌شات‌پذیر و اشتراک‌گذاری‌شدنیه.
3. سیستم دعوت + سکه رایگان، رشد ارگانیک ایجاد می‌کنه.
4. مچ طلایی روزانه باعث می‌شه کاربر هر روز به ربات برگرده.
5. جدول ستاره هفته یه عنصر رقابتی/بازی‌گونه اضافه می‌کنه.
